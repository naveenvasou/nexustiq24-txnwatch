# TxnWatch - Banking Transaction Risk Investigation

An intelligent risk investigation tool for compliance officers and bank investigators to assess customer transaction histories against internal banking risk policies.

## Overview
TxnWatch analyzes customer transaction records and flags potential risks based on predefined banking compliance rules. The system provides objective findings citing the applicable rules without asserting whether fraud occurred.

## Setup & Running
Install dependencies:
```bash
pip install -r requirements.txt
```

Run the application:
```bash
export GEMINI_API_KEY="your-gemini-api-key"
python app.py
```
Then visit http://localhost:8000 in your browser.
